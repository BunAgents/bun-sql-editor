# Bun SQL Editor Wiki

Welcome to the Bun SQL Editor wiki. Use the sidebar to navigate.

## What is Bun SQL Editor?

A lightweight, open-source SQL workbench distributed as a single self-contained binary. Connect to PostgreSQL, MySQL, MongoDB, and ClickHouse. No cloud, no signup, no installation required.

## Supported Databases

| Database | Schema | ERD | Autocomplete |
|----------|--------|-----|--------------|
| PostgreSQL | Full (tables, views, matviews, functions, sequences, triggers, indexes) | ✓ FK lines | SQL |
| MySQL | Tables, views, procedures, triggers | ✓ FK lines | SQL |
| MongoDB | Collections, views | — | Operators |
| ClickHouse | Multi-DB, tables, views, matviews | ✓ tables | CH functions |
