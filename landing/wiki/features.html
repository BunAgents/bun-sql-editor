Features

A complete reference of everything Bun SQL Editor can do.

Schema Explorer

The left sidebar shows your database schema as a collapsible tree. Click any item to expand it. Double-click a table or collection to open a query tab with a pre-filled SELECT * template.

Right-click any item to open the context menu with actions like Copy Name, Open ERD, VACUUM ANALYZE, and REINDEX TABLE (PostgreSQL).

Query Editor

The main editor area supports multiple tabs. Each tab is independent and can connect to a different database.

  • Run query — Ctrl+Enter (or click Run)
  • Format SQL — Ctrl+Shift+F
  • Query history — Ctrl+H
  • New tab — Ctrl+T
  • Close tab — Ctrl+W

Results are shown in a scrollable table below the editor. Click any column header to sort. The row count and elapsed time are shown in the result bar.

Inline cell editing

Double-click any cell in the result table to edit it in-place. The editor generates a safe UPDATE statement targeting the row by its primary key. Press Enter to apply or Escape to cancel.

⚠
Inline editing requires the result set to include the primary key column. Run SELECT * to ensure all columns are present.

SQL Formatter

Press Ctrl+Shift+F to format the current query. The formatter uses a token-based parser that respects string literals, comments, and identifiers — it will not mangle quoted strings or -- comments.

Query History

Press Ctrl+H to open the query history panel. Every query you execute is saved to localStorage. Click any entry to load it back into the editor.

ERD Diagrams

Click the ERD icon (🗺) on any schema in the sidebar, or right-click a schema and choose Open ERD, to open an entity-relationship diagram for that schema.

  • Drag table cards to rearrange
  • Scroll or pinch to zoom
  • Click and drag the background to pan
  • Fit to screen button resets the view

Foreign key relationships are drawn as bezier curves with arrowheads. ClickHouse ERDs show tables and columns only (no FK constraints in ClickHouse).

Autocomplete

The editor provides context-aware autocomplete triggered automatically as you type. Press Tab or Enter to accept a suggestion, Escape to dismiss.

  • Schema names — type the first letters of a schema
  • Table/view names — type after FROM or JOIN
  • Column names — type tablename. to see columns
  • SQL keywords — uppercase keywords like SELECT, WHERE

Autocomplete is database-aware: ClickHouse connections show ClickHouse-specific functions and engines; MongoDB connections show query operators and aggregation stages.

Identifiers with uppercase letters or spaces are automatically wrapped in double quotes when inserted.

PostgreSQL

Full feature support. Schema explorer shows tables, views, materialized views, functions, sequences, triggers, and indexes. ERD includes foreign key relationships with ON DELETE rules.

Right-click context menu extras:

  • VACUUM ANALYZE — reclaims storage and updates statistics
  • REINDEX TABLE — rebuilds all indexes on the table

MySQL

Schema explorer shows tables, views, stored procedures, and triggers scoped to the connected database. ERD includes foreign key relationships.

Use COLUMN_TYPE values (e.g. varchar(255), int unsigned) in column metadata for full type information.

MongoDB

MongoDB uses a JSON-based query format instead of SQL. Double-click any collection to get a pre-filled template:

{
  "collection": "users",
  "action": "find",
  "filter": {},
  "limit": 100
}

Supported actions:

ActionDescriptionExtra fields
findQuery documentsfilter, projection, sort, limit, skip
findOneReturn first matching documentfilter, projection
aggregateAggregation pipelinepipeline (array)
countCount matching documentsfilter
distinctDistinct values for a fieldfield, filter

Column inference: the editor samples up to 20 documents to infer field names and types. Because MongoDB is schemaless, types are shown as string | number when documents have mixed types.

ClickHouse

Multi-database schema explorer showing all databases (excluding system and information_schema). Detects View and MaterializedView engines from system.tables.

ClickHouse has no foreign key constraints, so ERD shows table structures only — no relationship lines.

Autocomplete includes 80+ ClickHouse-specific functions, table engines (MergeTree, ReplicatedMergeTree, etc.), and clauses (PREWHERE, FINAL, SETTINGS).
