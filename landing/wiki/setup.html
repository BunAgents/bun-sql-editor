Installation & Setup

Bun SQL Editor is distributed as a single self-contained binary. There is no installer, no runtime to install, and no Docker required.

Step 1 — Download

Go to the Releases page and download the binary for your platform:

🍎 macOS Apple Silicon

bun-sql-editor-macos-arm64

M1, M2, M3, M4 Macs

🍎 macOS Intel

bun-sql-editor-macos-x64

Intel Macs (pre-2020)

🪟 Windows

bun-sql-editor-windows-x64.exe

Windows 10/11 x64

🐧 Linux

bun-sql-editor-linux-x64

Ubuntu, Debian, Arch, etc.

Step 2 — Make executable (macOS / Linux)

Windows users can skip this step.

chmod +x bun-sql-editor-macos-arm64

Step 3 — Handle OS security prompt

⚠
Why does this happen? The binary is not code-signed. Code signing certificates cost $300–500/year per platform. The source code is fully public — you can build the binary yourself if you prefer not to trust the pre-built release.

macOS

Option A (easiest): Right-click the binary → Open → click Open in the dialog. You only need to do this once.

Option B: Go to System Settings → Privacy & Security → scroll down → click Open Anyway.

Option C (Terminal):

xattr -d com.apple.quarantine bun-sql-editor-macos-arm64

Windows

When SmartScreen appears: click More info → Run anyway.

Linux

No warning — just run it directly after chmod +x.

Step 4 — Run

# macOS / Linux
./bun-sql-editor-macos-arm64

# Windows
bun-sql-editor-windows-x64.exe

# Custom port (default is 3000)
PORT=8080 ./bun-sql-editor-macos-arm64

You should see:

SQL editor running on http://localhost:3000

Step 5 — Open in browser

Navigate to http://localhost:3000. The app loads immediately — no login required.

Build from source

You need Bun installed (curl -fsSL https://bun.sh/install | bash).

git clone https://github.com/BunAgents/bun-sql-editor
cd bun-sql-editor
bun install
bun run dev   # development mode with hot reload

To compile a single binary:

# macOS ARM
bun build --compile --target=bun-darwin-arm64 app/server.ts --outfile=bun-sql-editor

# Linux x64
bun build --compile --target=bun-linux-x64 app/server.ts --outfile=bun-sql-editor

# Windows x64
bun build --compile --target=bun-windows-x64 app/server.ts --outfile=bun-sql-editor.exe

Connecting to a database

Click the + button in the sidebar to add a new connection. Fill in the host, port, user, password, and database name. Click Test Connection to verify, then Save.

PostgreSQL defaults

Host: localhost   Port: 5432   User: postgres   DB: postgres

MySQL defaults

Host: localhost   Port: 3306   User: root   DB: mysql

MongoDB

Use a full connection URI in the Host field:

mongodb://localhost:27017
mongodb+srv://user:pass@cluster.mongodb.net

ClickHouse defaults

Host: http://localhost:8123   User: default   DB: default
✓
Connection details are stored in your browser's localStorage — they never leave your machine and are not sent to any server other than the local binary.
