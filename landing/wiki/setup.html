Installation & Setup

Bun SQL Editor is a single self-contained binary. No runtime, no Docker, no installer required.

Install — One Line

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/BunAgents/bun-sql-editor/main/install.sh | bash

The script:

  • Detects your platform (macOS arm64 / x64, Linux x64)
  • Downloads the latest binary from GitHub Releases
  • Removes the macOS quarantine flag automatically — no "damaged" warning
  • Installs to /usr/local/bin/bun-sql-editor (uses sudo if needed)

Windows

Open PowerShell and run:

irm https://raw.githubusercontent.com/BunAgents/bun-sql-editor/main/install.ps1 | iex

The script:

  • Downloads the latest binary from GitHub Releases
  • Runs Unblock-File to clear the SmartScreen flag
  • Installs to %LOCALAPPDATA%\bun-sql-editor\
  • Adds the install directory to your user PATH

Run

bun-sql-editor

Open http://localhost:3000 in your browser.

# Custom port (default: 3000)
PORT=8080 bun-sql-editor

Manual Download

Download the binary directly from GitHub Releases:

macOS Apple Silicon

bun-sql-editor-macos-arm64

M1, M2, M3, M4

macOS Intel

bun-sql-editor-macos-x64

Intel Macs (pre-2020)

Windows x64

bun-sql-editor-windows-x64.exe

Windows 10/11

Linux x64

bun-sql-editor-linux-x64

Ubuntu, Debian, Arch…

# macOS / Linux — make executable first
chmod +x bun-sql-editor-macos-arm64
./bun-sql-editor-macos-arm64

OS Security Warnings

ℹ
Use the install script to skip this entirely. The curl | bash and irm | iex scripts handle the quarantine/SmartScreen removal automatically.

If you downloaded manually:

macOS — "damaged and can't be opened"

Run in Terminal:

xattr -d com.apple.quarantine bun-sql-editor-macos-arm64

Or: right-click → Open → click Open in the dialog. You only need to do this once.

Windows — SmartScreen

Click More info → Run anyway. Or right-click the file → Properties → check Unblock → OK.

Linux

No warning — just chmod +x and run.

Build from Source

Requires Bun.

git clone https://github.com/BunAgents/bun-sql-editor
cd bun-sql-editor
bun install
bun run dev              # hot reload → http://localhost:3000
bun run build:client     # bundle TypeScript → app/public/app.js
bun test                 # 32 unit tests, no DB required

Compile a binary:

# macOS ARM
bun build --compile --target=bun-darwin-arm64 app/server.ts --outfile=bun-sql-editor

# Linux x64
bun build --compile --target=bun-linux-x64 app/server.ts --outfile=bun-sql-editor

# Windows x64
bun build --compile --target=bun-windows-x64 app/server.ts --outfile=bun-sql-editor.exe

Connecting to a Database

Click + in the sidebar, fill in the connection details, click Test, then Save.

Default connection values

PostgreSQL  localhost:5432   user: postgres   db: postgres
MySQL       localhost:3306   user: root       db: mysql
ClickHouse  http://localhost:8123   user: default   db: default
MongoDB     mongodb://localhost:27017
✓
Connection details are stored in your browser's localStorage — they never leave your machine.
