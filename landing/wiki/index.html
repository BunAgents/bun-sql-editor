What is Bun SQL Editor?

Bun SQL Editor is a web-based SQL workbench that runs entirely on your own machine. It is distributed as a single self-contained binary — download it, run it, open localhost:3000 in your browser, and connect to your databases.

It supports PostgreSQL, MySQL, MongoDB, and ClickHouse from a single interface, with features comparable to DBeaver or TablePlus.

How it works

The binary starts a small HTTP server on your machine. Your browser connects to localhost:3000 and the server acts as a proxy between the browser and your database. Because the server runs locally, your credentials never leave your machine.

ℹ
Why not a pure web app? Browsers cannot open raw TCP connections, which all major database protocols require. A local server is the only secure way to bridge the gap. Read the full explanation →
