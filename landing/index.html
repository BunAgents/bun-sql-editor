Features

Everything you need, nothing you don't

Built for developers who want a fast, keyboard-friendly SQL editor without the bloat of a full IDE.

🗄️

Multi-Database Support

Connect to PostgreSQL, MySQL, MongoDB, and ClickHouse from a single interface. Switch connections in seconds.

🔍

Schema Explorer

Browse tables, views, materialized views, sequences, triggers, and functions in a collapsible tree sidebar.

✏️

Smart Autocomplete

Context-aware SQL autocomplete with schema, table, and column suggestions. Handles case-sensitive identifiers automatically.

🗺️

ERD Diagrams

Visualize foreign key relationships per schema. Drag table cards, zoom, pan, and see bezier FK lines at a glance.

✏️

Inline Cell Editing

Double-click any result cell to edit it. Generates a safe UPDATE statement automatically targeting the right row by primary key.

🎨

SQL Formatter

Format messy SQL with Ctrl+Shift+F. Token-based parser that respects string literals, comments, and identifiers.

📜

Query History

Every query you run is saved locally. Press Ctrl+H to browse, search, and replay past queries instantly.

🔧

Maintenance Commands

Right-click any table to run VACUUM ANALYZE or REINDEX. Keeps your PostgreSQL databases healthy without memorizing syntax.

📱

PWA Installable

Install to your home screen or desktop for a native-app feel. Works offline for the UI shell — queries run through your local server.

Why Local

Why not a cloud-hosted PWA?

A fair question — here's the honest answer.

🔒 The Browser TCP Wall

Browsers cannot open raw TCP connections — and that's intentional. Database protocols like PostgreSQL wire protocol, MySQL binary protocol, and MongoDB BSON are all TCP-based. There is no way for a web page to connect directly to your database server without a backend proxy in between.

This means any web-based SQL editor — including Bun SQL Editor — requires a server to act as the bridge between your browser and your database. There is no purely client-side solution for connecting to external databases.

🤝 The Trust Problem

If that proxy server is hosted by someone else (a SaaS), your database credentials — host, port, username, password — must travel through their infrastructure. Even if they promise not to log them, you have to take their word for it.

Bun SQL Editor solves this by making you the server. The binary runs on your own machine. Your credentials never leave your computer. The browser talks to localhost, not a cloud endpoint. You can read every line of the source code and verify this yourself.

✗ Cloud-hosted SQL editors

Your credentials pass through a third-party server. You must trust their security, logging practices, and uptime.

✓ Bun SQL Editor (local binary)

The server is on your machine. Credentials go to localhost only. Open source — audit it yourself.

✗ Desktop app (signed)

Code signing requires $300–500/year certificates per platform. Closed binary — you have to trust it anyway.

✓ Bun SQL Editor (open source binary)

No signing required. macOS/Windows show a one-time warning — click "Open Anyway." Source is public so you know what runs.

Setup

Up and running in 30 seconds

No installation, no runtime dependencies, no Docker required.

1

Download the binary for your platform

Grab the latest release from GitHub Releases for your OS.

🍎 macOS (Apple Silicon)

bun-sql-editor-macos-arm64

🍎 macOS (Intel)

bun-sql-editor-macos-x64

🪟 Windows

bun-sql-editor-windows-x64.exe

🐧 Linux

bun-sql-editor-linux-x64

2

Make it executable (macOS / Linux)

Windows users can skip this step.

chmod +x bun-sql-editor-macos-arm64
3

Run it

The server starts on port 3000 by default. Set PORT to change it.

# macOS / Linux
./bun-sql-editor-macos-arm64

# Windows
bun-sql-editor-windows-x64.exe

# Custom port
PORT=8080 ./bun-sql-editor-macos-arm64
4

Open your browser

Navigate to http://localhost:3000 and connect to your database. That's it.

⚠️ macOS / Windows security warning

Because the binary is not code-signed (signing certificates cost $300–500/year per platform), your OS will show a security warning the first time you run it.

macOS: Right-click the binary → Open → click "Open" in the dialog. You only need to do this once. Alternatively: System Settings → Privacy & Security → Open Anyway.

Windows: Click "More info" → "Run anyway" in the SmartScreen dialog.

The source code is fully public. You can clone the repo, inspect every line, and build the binary yourself if you prefer not to trust a pre-built release.

Build from Source

Prefer to build it yourself?

You need Bun installed.

1

Clone and install

git clone https://github.com/BunAgents/bun-sql-editor
cd bun-sql-editor
bun install
2

Run in dev mode

bun run dev
3

Compile a single binary

bun build --compile --target=bun-darwin-arm64 app/server.ts --outfile=bun-sql-editor
