Features

Everything you need

Built for developers who want speed and simplicity over cloud complexity.

Multi-Database

PostgreSQL, MySQL, MongoDB, and ClickHouse in a single interface. Switch connections instantly.

Schema Explorer

Browse tables, views, materialized views, sequences, triggers, and functions in a collapsible tree.

Smart Autocomplete

Context-aware SQL completion with schema, table, and column hints. Handles case-sensitive identifiers.

ERD Diagrams

Visualize foreign key relationships per schema. Drag cards, zoom, pan, and see bezier FK lines.

Inline Editing

Double-click any result cell to edit it in-place. Generates a safe UPDATE statement automatically.

SQL Formatter

Format messy SQL with Ctrl+Shift+F. Token-based parser that respects literals and comments.

Query History

Every query is saved locally. Press Ctrl+H to browse and replay past queries instantly.

Maintenance Tools

Right-click any table to run VACUUM ANALYZE or REINDEX without memorizing syntax.

PWA Ready

Install to your desktop for a native-app feel. Service worker caches the UI shell offline.

Why local

Why not a cloud app?

An honest answer about browser limitations and data trust.

✗
Cloud-hosted SQL editors
Your credentials pass through a third-party server. You must trust their security, logging, and uptime.
✓
Bun SQL Editor
The server runs on your machine. Credentials go to localhost only. Source is public — audit it yourself.
ℹ
The browser TCP wall — Browsers cannot open raw TCP connections by design. PostgreSQL, MySQL, and MongoDB use TCP binary protocols. Any web-based SQL editor needs a backend proxy between your browser and your database. Bun SQL Editor makes you that server.

Quick start

Up in 30 seconds

No runtime. No Docker. One command installs and removes the OS security warning automatically.

1

Install — macOS / Linux

curl -fsSL https://raw.githubusercontent.com/BunAgents/bun-sql-editor/main/install.sh | bash

Detects your platform, downloads the binary, removes the quarantine flag, installs to /usr/local/bin.

1

Install — Windows (PowerShell)

irm https://raw.githubusercontent.com/BunAgents/bun-sql-editor/main/install.ps1 | iex

Downloads the binary, clears the SmartScreen flag, adds to your user PATH.

2

Run it

bun-sql-editor
3

Open in your browser

http://localhost:1983
ℹ
Prefer to download manually? Grab the binary from Releases. See Setup docs for platform-specific instructions.
